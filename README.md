# Industrial Mineral Supply

Astro preview for Industrial Mineral Supply in Griffith, IN. Built from the Wild Card Astro starter with Tailwind CSS v4 and Vue 3 islands using flowbite-vue.

- `npm install`
- `npm run dev` starts the dev server
- `npm run build` runs `astro build --timings` and writes the output to `build-timings.txt`

Pages are static. The navbar, service tabs, gallery lightbox, and product accordion are Vue islands. The shop does not take orders, payments, or messages. The site sends `noindex`.
